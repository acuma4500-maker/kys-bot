# 🪖 Kışla Yönetim Sistemi (KYS)

Telegram tabanlı, adil görev dağıtımı yapan askeri yönetim sistemi.

## Özellikler

- 🧹 Günlük temizlik listesi
- 👷 Gün içi iş dağıtımı
- 📊 İstatistikler
- ⚖️ Adalet algoritması
- ☁️ Deno Deploy desteği

Teknolojiler:

- Deno
- TypeScript
- grammY
- Deno KV
- Telegram Bot API
